## 推荐阅读顺序

1. 用官方 Installation 和 Quickstart 完成安装、Setup、首次聊天与 Doctor。
2. 学习 Desktop 和 Feishu 官方文档，完成真实界面的基础回执。
3. 在每课结束时选择一份社区资料观察界面或案例，不直接照搬旧命令。
4. 用 Skills、Memory、Cron 与 Security 官方文档完成课程实验。
5. 通过橙皮书建立整体理解，再用 awesome 目录寻找特定扩展。

## 引用原则

- 官方资料是命令、配置键和安全行为的事实基准。
- 社区资料用于补充中文解释、界面观察和场景灵感。
- 视频主题只采用公开标题、简介与章节元数据；具体命令回查官方文档。
- 需要登录、已失效或无法公开验证的入口不进入学习资料索引。
- 所有摘要均为本项目原创整理，不代表原作者或 Nous Research 背书。
